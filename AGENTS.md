# Autonomous Agent Guidelines

## Permissions & Scope
- **Directory Access**: You have full authority and explicit permission to create, edit, overwrite, organize, and delete files inside `public/notes/` without asking for user confirmation in chat.
- **Workflow Mode**: Follow an **agentic development** workflow:
  - Act autonomously toward the user's high-level objectives.
  - Implement full solutions, verify file contents, and report results when finished.
  - Do not stop to ask for confirmation on intermediate steps or standard file operations in `public/notes/`.
