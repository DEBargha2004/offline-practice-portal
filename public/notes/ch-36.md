# Chapter 36: Software Defined IoT Networking (SD-IoT) — Part II: Mobility & Cellular

## Core Concept
Integrating Software Defined Networking with mobile cellular IoT, vehicular networks, and 5G small cells enables dynamic radio resource slicing, seamless inter-cell handoffs, and multi-radio traffic steering across Wi-Fi, 4G, and 5G spectrums.

---

## 1. Flow Table Paradigm in Heterogeneous Mobile IoT
* **Cross-Technology Flow Abstraction:** In modern smart environments, devices shift between cellular (NB-IoT, LTE-M), Wi-Fi, and Zigbee.
* **Unified Flow Rules:** Instead of relying on technology-specific routing, the SD-IoT controller installs unified flow rules across access points and base stations.
* **Granular Traffic Steering:** High-bandwidth video feeds are automatically routed over high-throughput Wi-Fi, while low-latency emergency telemetry flows over cellular small cells.

---

## 2. Logically Centralized Control in Cellular IoT
* **Inter-Cell Interference Coordination (ICIC):** Traditional cellular base stations (eNodeBs / gNodeBs) must negotiate radio frequency allocations using distributed peer protocols (e.g., X2 interface).
* **SDN-Enabled Cellular Control:** A logically centralized SDN controller observes signal-to-interference ratios across all adjacent cells, calculating and pushing optimal frequency and power assignments in real time.
* **Seamless Handoff Management:** As mobile nodes (vehicles, drones) travel across cells, the controller proactively installs forwarding rules on target base stations before the physical radio disconnection occurs, eliminating packet drop during handovers.

---

## 3. Network Slicing and Virtualization in SD-IoT
* **Network Slicing:** Partitioning a single physical network infrastructure into multiple isolated, independent virtual networks customized for specific application requirements:
  * **Ultra-Reliable Low-Latency Communication (URLLC) Slice:** Dedicated resources for industrial robotics and autonomous vehicle crash avoidance.
  * **Massive Machine-Type Communication (mMTC) Slice:** Optimized for millions of low-power environmental sensors reporting sporadic data.
  * **Enhanced Mobile Broadband (eMBB) Slice:** High-bandwidth channel allocation for surveillance cameras.

---

## Key Exam Takeaways
* **Logically Centralized Advantage:** Eliminates intercellular radio interference through holistic network-wide frequency coordination.
* **Proactive Handoffs:** Rules are installed on target base stations prior to device movement, preventing packet loss.
* **Network Slicing Concept:** Dynamically allocating virtual end-to-end networks over shared physical infrastructure (URLLC, mMTC, eMBB).
* **Multi-Radio Steering:** Dynamically directing flows to Wi-Fi vs. Cellular based on live QoS metrics.
