# Chapter 23: Introduction to Arduino — Part II: Programming Constructs

## Core Concept
Programming intelligent IoT behavior requires moving beyond simple linear code to structured control flow, multi-branch decisions, array buffers, timing functions, and hardware interrupt routines.

---

## 1. Operators and Control Structures
* **Arithmetic & Compound Assignment:** `+`, `-`, `*`, `/`, `%` (modulo), `+=`, `-=`, `++`, `--`.
* **Comparison & Boolean Logic:** `==`, `!=`, `<`, `>`, `<=`, `>=`, `&&` (AND), `||` (OR), `!` (NOT).
* **Conditional Branching:**
  * `if ... else if ... else`: Evaluates runtime boolean expressions.
  * `switch ... case ... default`: Evaluates multi-way integer or character branches efficiently.
* **Loops:**
  * `for (init; condition; increment)`: Deterministic iteration across counters or arrays.
  * `while (condition)`: Executes as long as a condition holds true.
  * `do ... while (condition)`: Guarantees execution of the code block at least once before testing the condition.

---

## 2. Advanced Timing and Hardware Interrupts
* **Blocking vs. Non-Blocking Timing:**
  * `delay()` stops all CPU processing during the pause; the MCU cannot monitor sensor inputs or catch events during this time.
  * `millis()` returns the number of milliseconds since the board began running (rolls over after roughly 50 days). Enables non-blocking state machines by comparing timestamps.
* **Hardware Interrupts:**
  * Allows external events (such as an emergency button press or optical encoder pulse) to instantly suspend main `loop()` execution and run an **Interrupt Service Routine (ISR)**.
  * Configured via `attachInterrupt(digitalPinToInterrupt(pin), ISR_function, mode)`.
  * **Interrupt Modes:** `RISING` (LOW to HIGH), `FALLING` (HIGH to LOW), `CHANGE` (any edge), `LOW` (trigger when pin is LOW).
  * **ISR Rules:** Keep routines extremely fast and compact; never call `delay()` or heavy serial printing inside an ISR; variables shared between an ISR and `loop()` must be declared `volatile`.

---

## 3. Serial Communication
* Uses the Universal Asynchronous Receiver-Transmitter (UART) interface on digital pins 0 (RX) and 1 (TX).
* `Serial.begin(baudrate)`: Initializes communication (common baud rates: 9600, 115200).
* `Serial.print()` / `Serial.println()`: Transmits ASCII text to the host computer or external modem.
* `Serial.available()`: Returns the number of bytes received and waiting in the serial buffer.
* `Serial.read()`: Reads the incoming serial byte.

---

## Key Exam Takeaways
* **Volatile Keyword:** Mandatory for variables modified inside an Interrupt Service Routine (ISR) to prevent compiler register optimization errors.
* **Non-Blocking Timing:** Built using `millis()` rather than CPU-blocking `delay()`.
* **External Interrupt Pins on Uno:** Digital pins 2 (Interrupt 0) and 3 (Interrupt 1).
* **UART Pins:** Pin 0 (RX) and Pin 1 (TX).
* **ISR Constraints:** Must be brief; cannot rely on `delay()` because interrupts are temporarily disabled during execution.
