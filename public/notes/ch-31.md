# Chapter 31: Implementation of IoT with Raspberry Pi — Part II: Networked Telemetry

## Core Concept
Building on standalone sensor interfacing, this chapter explores the implementation of a full networked client-server telemetry system: reading combined temperature and humidity data from a DHT sensor on a Raspberry Pi client and transmitting periodic datagrams over UDP to a central desktop server.

---

## 1. Client-Side Implementation: Sensor to Socket
* **Sensor Integration:** Connecting a DHT11/DHT22 digital sensor to a designated GPIO pin on the Raspberry Pi using Python libraries (such as Adafruit DHT).
* **Payload Serialization:**
  * Raw float readings (e.g., temperature of 25.4 C and humidity of 65.2% RH) are packaged into a delimited string: `"25.4,65.2"`.
* **UDP Client Socket Flow:**
  1. Socket instantiated: `client = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)`
  2. String converted to binary bytes: `payload = "25.4,65.2".encode('utf-8')`
  3. Packet dispatched without connection handshake: `client.sendto(payload, (SERVER_IP, PORT))`
  4. Script sleeps for a sampling interval (e.g., 2 seconds) and repeats in a loop.

---

## 2. Server-Side Implementation: Receiving and Parsing
* **Binding and Listening:**
  1. Server instantiates UDP socket: `server = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)`
  2. Binds to network interface and listening port: `server.bind(('0.0.0.0', PORT))`
  3. Blocks on incoming packets: `data, client_address = server.recvfrom(1024)`
* **Decoding and Parsing:**
  * Incoming byte buffer is decoded: `raw_string = data.decode('utf-8')`
  * String is split along the delimiter: `temp_str, hum_str = raw_string.split(',')`
  * Strings are cast back into numeric floats for processing or logging.

---

## 3. Reliability and Network Trade-offs
* **Why UDP for Sensor Telemetry:** Eliminates TCP connection handshakes, ACK round-trips, and persistent socket maintenance. If an occasional reading is lost due to packet drop, the next periodic reading arrives shortly.
* **Firewall Considerations:** UDP listening ports must be opened on the server operating system to allow inbound client datagrams.

---

## Key Exam Takeaways
* **Delimiter Role:** Character (e.g., comma `,`) separating composite multi-sensor readings within a single transmitted string.
* **Socket Binding:** `server.bind((HOST, PORT))` binds the server listening socket to incoming network packets.
* **Decoding Requirement:** Received socket bytes must be decoded back into strings (`.decode('utf-8')`) before string splitting.
* **UDP Fit:** Connectionless, lightweight transport ideal for high-frequency periodic environmental updates.
