# Chapter 41: Cloud Computing — Part V: OpenStack Architecture

## Core Concept
OpenStack is the industry-standard open-source cloud operating system. It provides an extensible set of modular services that control large pools of compute, storage, and networking resources across enterprise data centers, managed through common APIs and a unified web dashboard.

---

## 1. Modular Services in OpenStack
OpenStack is constructed from independent, collaborative microservices:

* **Horizon (Dashboard):** Web-based graphical user interface (GUI) allowing administrators and cloud tenants to provision VMs, assign IP addresses, and monitor usage quotas.
* **Keystone (Identity Service):** Central authentication and authorization service across all OpenStack modules. Issues authentication tokens, validates permissions, and maintains user/tenant service catalogs.
* **Nova (Compute Engine):** Manages the lifecycle of compute instances (virtual machines). Interacts with underlying hypervisors (KVM, QEMU, VMware) to schedule, spawn, suspend, and terminate VMs.
* **Neutron (Networking):** Software-defined networking service provisioning virtual switches, subnets, routers, floating public IPs, and security groups.
* **Glance (Image Service):** Repository storing virtual machine disk images and server templates (e.g., Ubuntu, CentOS ISOs/raw images) used by Nova to instantiate new VMs.
* **Cinder (Block Storage):** Persistent block-level storage volumes attached directly to running Nova VM instances (similar to AWS EBS).
* **Swift (Object Storage):** Highly scalable, distributed object storage system for unstructured data (sensor binary blobs, images, backup archives) accessible via HTTP REST calls (similar to AWS S3).
* **Ceilometer (Telemetry & Metering):** Monitors resource utilization, collects performance counters, and feeds data to billing engines.

---

## Comparison: Cinder vs. Swift Storage
| Feature | Cinder (Block Storage) | Swift (Object Storage) |
| :--- | :--- | :--- |
| **Data Format** | Raw drive blocks, formatted with filesystems | Unstructured binary objects + metadata |
| **Access Method** | Mounted directly to running compute VM | HTTP/HTTPS REST API requests |
| **Typical Use** | Database drives, OS boot disks, active VM storage | Long-term sensor telemetry archives, media files |
| **Persistence** | Tied to active VM attachments | Highly distributed across server clusters |

---

## Key Exam Takeaways
* **Horizon Role:** Web-based GUI dashboard for managing OpenStack resources.
* **Keystone Role:** Identity and authentication service managing security tokens.
* **Nova Role:** Core compute engine orchestrating virtual machines.
* **Glance Role:** Disk image registry storing operating system templates.
* **Cinder vs. Swift:** Cinder provides mountable block storage; Swift provides HTTP-accessible object storage.
