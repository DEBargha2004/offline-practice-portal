# Chapter 38: Cloud Computing — Part II: Service Models (IaaS, PaaS, SaaS)

## Core Concept
Cloud services are categorized into three primary architectural delivery models—Infrastructure as a Service (IaaS), Platform as a Service (PaaS), and Software as a Service (SaaS). Each model represents a different division of responsibility between the consumer and the cloud service provider.

---

## 1. The Three Service Models

### 1. Infrastructure as a Service (IaaS)
* **What is Provided:** Fundamental computing resources: raw virtual machines, physical servers, block/object storage, and virtual network switches.
* **Customer Manages:** Operating system (OS), middleware, runtime environments, application code, and data.
* **Provider Manages:** Physical data center facilities, cooling, physical servers, virtualization hypervisors, and core networking hardware.
* **Examples:** Amazon EC2, Google Compute Engine, Microsoft Azure Virtual Machines.

### 2. Platform as a Service (PaaS)
* **What is Provided:** A managed execution and development environment including operating systems, programming language runtimes, web servers, and managed databases.
* **Customer Manages:** Application source code and application-level configuration settings.
* **Provider Manages:** Hardware, virtualization, operating system patches, runtime upgrades, database clustering, and automatic scaling.
* **Examples:** AWS Elastic Beanstalk, Google App Engine, Heroku.

### 3. Software as a Service (SaaS)
* **What is Provided:** Complete, fully functional applications hosted on cloud infrastructure and accessed directly over web browsers or thin-client APIs.
* **Customer Manages:** User account profiles and personal application preferences.
* **Provider Manages:** Everything: infrastructure, operating systems, code updates, security patches, data persistence, and high availability.
* **Examples:** Google Workspace, Microsoft 365, Salesforce.

## 2. Shared Responsibility Comparison
| Layer | Traditional On-Premise | IaaS | PaaS | SaaS |
| :--- | :--- | :--- | :--- | :--- |
| **Applications** | Customer | Customer | Customer | **Provider** |
| **Data** | Customer | Customer | Customer | **Provider** |
| **Runtime** | Customer | Customer | **Provider** | **Provider** |
| **Middleware** | Customer | Customer | **Provider** | **Provider** |
| **Operating System** | Customer | Customer | **Provider** | **Provider** |
| **Virtualization** | Customer | **Provider** | **Provider** | **Provider** |
| **Servers & Storage** | Customer | **Provider** | **Provider** | **Provider** |
| **Networking** | Customer | **Provider** | **Provider** | **Provider** |

---

## Key Exam Takeaways
* **Highest Consumer Control:** IaaS (consumer controls OS, runtime, and network configurations).
* **Developer Productivity Model:** PaaS (developer writes code without managing underlying OS or servers).
* **End-User Application Model:** SaaS (complete turnkey software consumed over web browsers).
* **Division of Responsibility:** IaaS abstracts physical hardware; PaaS abstracts the operating system and runtime; SaaS abstracts everything.
