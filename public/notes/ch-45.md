# Chapter 45: Fog Computing — Part II: Architecture & Applications

## Core Concept
Fog computing is not a replacement for cloud computing; it is a complementary, hierarchical extension. This chapter examines the internal architecture of Fog nodes, data offloading strategies, and practical deployment applications across smart infrastructure.

---

## 1. Fog Nodes: Hardware & Capabilities
* A **Fog Node** is any networked device capable of compute, storage, and network connectivity situated between end devices and the cloud.
* **Hardware Forms:** Industrial routers, multi-access edge computing (MEC) base stations, smart gateways, local Linux servers, or micro-data centers.
* **Core Functions:**
  * **Data Filtering and De-duplication:** Discards redundant sensor readings (e.g., ignoring 100 consecutive identical temperature readings) to minimize upstream bandwidth usage.
  * **Protocol Normalization:** Translates proprietary industrial fieldbus protocols into standard MQTT/HTTP.
  * **Local Event Processing:** Triggers immediate local actuation within milliseconds.

---

## 2. Hierarchical Processing Division
| Operational Tier | Latency | Infrastructure | Typical Tasks |
| :--- | :--- | :--- | :--- |
| **Edge Devices** | Microseconds | Sensors, microcontrollers, smart meters | Raw physical data acquisition, basic threshold triggers. |
| **Fog Layer** | Milliseconds (<10 ms) | Local gateways, roadside units, local servers | Real-time emergency actuation, data cleansing, local caching. |
| **Cloud Layer** | Seconds / Minutes | Hyperscale data centers (AWS, Azure) | Multi-year historical analytics, machine learning model training, enterprise reporting. |

---

## 3. Application Domains for Fog Computing
* **Smart Traffic & Autonomous Vehicles:** Roadside units (RSUs) process live intersection video feeds to adjust traffic signals and warn incoming vehicles of hazards in real time.
* **Smart Healthcare:** Wearable monitors communicate with hospital bedside fog hubs to detect cardiac arrhythmias instantly, sounding local nurse alarms before logging trends to cloud records.
* **Smart Grid:** Local substation fog controllers balance microgrid energy loads and isolate electrical transformer faults within milliseconds to prevent widespread blackouts.

---

## Key Exam Takeaways
* **Complementary Relationship:** Fog handles latency-sensitive real-time processing; Cloud handles massive long-term data warehousing.
* **Data Cleansing Role:** Fog filters and aggregates redundant data at the network edge, cutting cloud bandwidth consumption.
* **Typical Fog Latency:** Millisecond response times compared to hundreds of milliseconds for cloud calls.
* **Target Applications:** Autonomous driving, smart power grid fault management, and emergency medical monitoring.
