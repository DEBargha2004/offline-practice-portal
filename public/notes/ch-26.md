# Chapter 26: Introduction to Python Programming — Part I

## Core Concept
Python is a high-level, interpreted, dynamically typed programming language known for clean syntax and rapid development. In IoT ecosystems, Python is the primary language for single-board computers (such as Raspberry Pi) and edge computing gateways, facilitating rapid sensor interfacing, socket networking, and data processing.

---

## 1. Language Characteristics
* **Interpreted:** Executes code line-by-line via the Python interpreter without requiring separate explicit compilation into machine binaries.
* **Dynamically Typed:** Variable types are resolved automatically at runtime without explicit type declarations.
* **Strict Indentation:** Uses consistent whitespace indentation (conventionally 4 spaces) to define code blocks, replacing curly braces (`{}`) found in C/C++.

---

## 2. Core Built-In Data Structures
* **Lists (`[...]`):**
  * Ordered, mutable sequences of heterogeneous items.
  * Supports indexing, slicing, appending (`list.append(x)`), and sorting.
* **Tuples (`(...)`):**
  * Ordered, **immutable** sequences. Once created, elements cannot be modified, added, or removed.
  * Faster than lists; commonly used for fixed configuration constants and coordinates.
* **Dictionaries (`{key: value}`):**
  * Unordered collections of key-value pairs; keys must be immutable and unique.
  * Optimized for rapid key lookups, mirroring JSON data structures used in IoT telemetry APIs.
* **Sets (`{...}`):**
  * Unordered collections of unique elements; automatically eliminates duplicates and supports mathematical set operations (union, intersection, difference).

---

## 3. Control Flow Constructs
* **Conditionals:** `if`, `elif`, `else` blocks evaluating boolean logic expressions.
* **For Loops:** Iterates directly over sequences and iterable objects (`for item in sequence:`).
* **While Loops:** Repeats code execution as long as a boolean condition remains true.
* **Functions (`def`):** Reusable blocks of code that accept arguments and return output values using the `return` keyword.

---

## Key Exam Takeaways
* **Code Block Definition:** Enforced via indentation whitespace rather than curly braces.
* **Mutable vs. Immutable Sequences:** Lists are mutable (can change); Tuples are immutable (cannot change).
* **Dictionary Mechanics:** Hash-map style key-value mapping ideal for JSON-like IoT telemetry.
* **Execution Paradigm:** Interpreted at runtime, accelerating prototyping and deployment on Linux-based edge boards.
