# Chapter 10: Connectivity Technologies — Part II: 6LoWPAN & RFID

## Core Concept
Integrating constrained wireless sensors directly with the global internet requires adapting large internet protocols for small radio packets. 6LoWPAN solves this by compressing IPv6 headers onto IEEE 802.15.4 frames. Alongside this, RFID provides contactless object identification and tracking without requiring batteries on tags.

---

## 1. 6LoWPAN (IPv6 over Low-Power WPAN)
Defined in IETF RFC 4944 and RFC 6282, 6LoWPAN enables standard IPv6 packets to be transmitted over constrained IEEE 802.15.4 radio links.

### The Core Problem
* **Standard IPv6 MTU:** Minimum transmission unit is 1280 bytes, with a fixed 40-byte base header.
* **IEEE 802.15.4 Frame Limit:** Maximum physical payload is only 127 bytes (often leaving only around 81 to 102 bytes for application data after MAC headers).
* 6LoWPAN introduces an intermediate **Adaptation Layer** between the Data Link (MAC) layer and the Network (IPv6) layer.

### Adaptation Layer Mechanisms
* **Header Compression:** Compresses the 40-byte IPv6 header down to as few as 2 to 4 bytes by eliminating redundant fields and deriving addresses from 802.15.4 MAC addresses.
* **Fragmentation and Reassembly:** Breaks oversized IPv6 packets (up to 1280 bytes) into smaller chunks matching the 127-byte limit:
  * First fragment includes a datagram size and tag.
  * Subsequent fragments include a datagram offset indicating their position.
* **Mesh Routing:**
  * Uses 16-bit short PAN addresses locally, or 64-bit globally unique extended addresses.
  * Employs routing protocols like **RPL** (Routing Protocol for Low-Power and Lossy Networks) and **LOADng** (a lightweight AODV derivative) to navigate mesh topologies.

## 2. RFID (Radio-Frequency Identification)
A contactless technology that uses electromagnetic radio waves to automatically identify, locate, and read data stored on tags attached to objects.

### System Components
* **RFID Tag (Transponder):** Attached to objects; consists of a microchip and an antenna.
* **RFID Reader (Transceiver):** Emits radio frequency signals and reads incoming data back from nearby tags.
* **Host Application / Middleware:** Processes tag identifiers and updates inventory or access systems.

### Tag Classifications
* **Passive RFID Tags:**
  * No internal battery.
  * Powered entirely by the electromagnetic wave field emitted by the reader antenna (inductive or backscatter coupling).
  * Very low cost, tiny size, and near-infinite operational lifespan.
  * Short read range (centimeters up to several meters).
* **Active RFID Tags:**
  * Contains an onboard battery and active transmitter.
  * Broadcasts its own signal autonomously over longer distances (tens of meters).
  * Higher unit cost and limited battery lifetime.
* **Semi-Passive (Battery-Assisted) Tags:**
  * Battery powers internal sensor circuits and chip logic, but uses reader backscatter energy to transmit data back.

---

## Comparison: Passive vs. Active RFID
| Property | Passive RFID | Active RFID |
| :--- | :--- | :--- |
| Internal Battery | No | Yes |
| Power Source | Reader's RF field | Onboard battery |
| Read Range | Short (a few centimeters to ~6m) | Long (up to 100m+) |
| Lifespan | Virtually unlimited | Limited by battery life |
| Unit Cost | Very low | Moderate to high |
| Typical Use | Retail barcodes replacement, inventory badges | Vehicle toll collection, real-time fleet tracking |

---

## Key Exam Takeaways
* **6LoWPAN Function:** Enables IPv6 communication over low-power IEEE 802.15.4 links.
* **Adaptation Layer Tasks:** IPv6 header compression, packet fragmentation, and mesh routing.
* **RPL Role:** Standard distance-vector routing protocol designed for low-power lossy networks.
* **Passive RFID Powering:** Operates without a battery, drawing power from the reader's RF field.
* **IPv6 MTU vs. 802.15.4 Frame:** 1280 bytes minimum IPv6 MTU compressed into 127-byte radio frames.
