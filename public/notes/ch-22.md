# Chapter 22: Introduction to Arduino — Part I: Hardware & IDE

## Core Concept
Arduino is an open-source physical computing platform based on accessible microcontroller hardware and an intuitive development environment. It serves as an industry-standard platform for rapid prototyping in embedded systems and edge IoT devices.

---

## 1. Hardware Architecture: Arduino Uno
The Arduino Uno is built around the **Microchip ATmega328P** 8-bit AVR microcontroller:
* **Operating Voltage:** 5V (Input voltage via barrel jack recommended at 7-12V).
* **Clock Speed:** 16 MHz ceramic resonator/crystal oscillator.
* **Memory Architecture:**
  * **Flash Memory (32 KB):** Non-volatile memory storing the compiled program code (0.5 KB reserved for the bootloader).
  * **SRAM (2 KB):** Volatile static RAM storing active program variables and runtime execution stack.
  * **EEPROM (1 KB):** Non-volatile memory for storing persistent calibration constants or configuration data across power resets.
* **Input/Output Pins:**
  * **14 Digital I/O Pins (Pins 0 to 13):** Can be configured as inputs or outputs using software commands.
  * **6 PWM Pins (Pins 3, 5, 6, 9, 10, 11):** Marked with a tilde symbol (`~`); simulate analog output voltages using 8-bit Pulse Width Modulation (values from 0 to 255).
  * **6 Analog Input Pins (A0 to A5):** Connect to an onboard 10-bit Successive Approximation Analog-to-Digital Converter (ADC). Reads 0V to 5V inputs as integer values ranging from 0 to 1023.

---

## 2. Software Architecture: The Arduino Sketch
An Arduino program is referred to as a **Sketch** (written in a C/C++ derivative) and is structured around two mandatory core functions:
1. `void setup()`
   * Runs exactly once when the board powers up or is reset.
   * Used to initialize pin modes (`pinMode`), start serial communication (`Serial.begin`), and instantiate library objects.
2. `void loop()`
   * Executes continuously in an infinite loop after `setup()` finishes.
   * Houses the core runtime logic: reading sensors, evaluating conditions, calculating values, and toggling actuators.

---

## 3. Fundamental Arduino API Functions
* `pinMode(pin, mode)`: Configures a pin as `INPUT`, `OUTPUT`, or `INPUT_PULLUP`.
* `digitalWrite(pin, value)`: Sets a digital output pin to `HIGH` (5V) or `LOW` (0V).
* `digitalRead(pin)`: Reads an incoming digital logic state (`HIGH` or `LOW`).
* `analogRead(pin)`: Reads an analog voltage on pins A0-A5, returning an integer from 0 to 1023 (resolution of roughly 4.9 mV per step).
* `analogWrite(pin, value)`: Generates a PWM wave on designated PWM pins (accepts values 0 to 255).
* `delay(ms)`: Pauses execution for a specified number of milliseconds.

---

## Key Exam Takeaways
* **Primary Microcontroller:** ATmega328P running at 16 MHz and 5V logic.
* **Memory Distribution:** 32 KB Flash, 2 KB SRAM, 1 KB EEPROM.
* **Analog ADC Resolution:** 10-bit resolution producing values between 0 and 1023.
* **PWM Output Resolution:** 8-bit resolution accepting values between 0 and 255 across 6 specific pins.
* **Mandatory Sketch Functions:** `setup()` (runs once) and `loop()` (runs continuously).
