# Chapter 32: Implementation of IoT with Raspberry Pi — Part III: Storage & Visualization

## Core Concept
Raw telemetry received at a central IoT server must be systematically parsed, persisted into historical storage files (CSV), and visualized in real time using graphical plotting libraries to provide actionable insights.

---

## 1. Persistent Data Logging
* Incoming telemetry streams must be permanently recorded to disk to support trend analysis, auditing, and algorithmic machine learning.
* **CSV Datalogging Structure:**
  * Files are appended continuously with structured rows: `Timestamp, Temperature, Humidity`.
  * Using Python context management ensures each row is flushed safely to storage:
    ```python
    with open("sensor_log.csv", "a") as f:
        f.write(f"{timestamp},{temp},{hum}\n")
    ```

---

## 2. Real-Time Graphical Visualization: Matplotlib
* **Matplotlib:** The primary plotting and charting library in Python.
* **Time-Series Plotting:**
  * Generating dual-axis charts with time along the horizontal X-axis, temperature on the primary vertical Y-axis, and humidity on the secondary vertical axis.
* **Dynamic Real-Time Updating:**
  * Using `matplotlib.animation.FuncAnimation` or iterative figure drawing (`plt.pause()`) to continuously re-render live incoming data points without restarting the script.
* **Threshold Highlighting:** Visually highlighting abnormal spikes (such as temperatures exceeding critical safety bounds) with colored marker lines or alert boxes.

---

## 3. Complete End-to-End Pipeline Summary
1. **Perception:** DHT sensor samples physical ambient variables.
2. **Edge Processing:** Raspberry Pi reads raw bits, formats a CSV string, and encodes bytes.
3. **Transmission:** UDP socket dispatches packets over local Wi-Fi.
4. **Ingestion:** Central server receives datagrams, decodes bytes, and splits values.
5. **Storage:** Appends structured records with server timestamps into persistent CSV files.
6. **Visualization:** Real-time Matplotlib charts display live graphs on system dashboards.

---

## Key Exam Takeaways
* **Storage Mode:** Append mode (`'a'`) prevents historical sensor records from being overwritten.
* **Timestamp Necessity:** Telemetry must be paired with time-of-capture records to enable meaningful time-series graphing.
* **Matplotlib Function:** Standard Python data visualization library for rendering live IoT time-series plots.
* **End-to-End IoT Pipeline:** Sensing -> Edge Processing -> Network Transport -> Ingestion -> Storage -> Real-Time Visualization.
