# Chapter 60: Activity Monitoring — Part II: Smartphone Sensing & WebSockets

## Core Concept
This chapter explores the end-to-end implementation of a real-time human activity monitoring system using everyday smartphones as data acquisition clients, streaming high-frequency multi-axis inertial telemetry over persistent WebSockets to asynchronous Python servers.

---

## 1. Built-In Smartphone Sensor Suite
Modern smartphones feature a comprehensive array of Micro-Electro-Mechanical Systems (MEMS) sensors:
* **Accelerometer:** Measures linear acceleration forces along three orthogonal axes (X, Y, Z), including dynamic body movement and the static 1g gravitational vector.
* **Gyroscope:** Measures angular rate of rotation (pitch, roll, yaw) around the device axes, tracking device tilt and rotational posture.
* **Magnetometer:** Measures ambient magnetic field strength relative to magnetic north, serving as a digital compass to resolve directional heading.
* **GPS Module:** Satellite positioning tracking geographic coordinates, altitude, and ground speed across outdoor environments.

---

## 2. Real-Time Full-Duplex Networking: WebSockets
* **The Telemetry Challenge:** Inertial sensor sampling rates typically operate at 50 Hz to 100 Hz. Using traditional HTTP REST calls introduces unacceptable HTTP request header overhead and connection latency.
* **WebSockets Protocol:**
  * Establishes a persistent, bidirectional, full-duplex communication channel over a single TCP connection initiated through an HTTP handshake.
  * Allows the smartphone client to stream continuous binary or JSON sensor vectors with minimal framing overhead (as low as 2 bytes per frame).

---

## 3. Asynchronous Server Architecture in Python
* **Autobahn Python:** High-performance open-source library implementing WebSocket and WAMP (Web Application Messaging Protocol) specifications.
* **Twisted Engine:** Event-driven, asynchronous networking framework powering the Autobahn server. Handles hundreds of simultaneous concurrent smartphone sensor streams without spawning heavy operating system threads.
* **Real-Time Processing:** Incoming inertial streams are evaluated in memory to detect critical acceleration spikes characteristic of elderly falls, immediately pushing warning notifications to caregivers.

---

## Key Exam Takeaways
* **Primary Smartphone Sensors:** Accelerometer (linear acceleration), Gyroscope (angular rotation), Magnetometer (heading), GPS (location).
* **WebSockets Advantage:** Full-duplex persistent TCP connection with negligible per-packet framing overhead.
* **Why Not HTTP:** HTTP request-response headers cause excessive latency and network bandwidth bottlenecks at high sampling rates (50-100 Hz).
* **Autobahn & Twisted:** Asynchronous, event-driven Python libraries used to build scalable real-time WebSocket telemetry servers.
* **Fall Detection Principle:** Rapid acceleration spike along the vertical axis followed by an abrupt orientation shift to horizontal rest.
