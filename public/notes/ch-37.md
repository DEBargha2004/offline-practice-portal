# Chapter 37: Cloud Computing — Part I: Foundations & NIST Definition

## Core Concept
Cloud computing delivers on-demand, scalable computing resources (servers, storage, databases, networking, software) over the internet on a metered pay-per-use basis. It provides the computational and storage backbone for IoT, ingesting massive sensor streams that exceed the capacity of local edge devices.

---

## 1. NIST Five Essential Characteristics
According to the National Institute of Standards and Technology (NIST), cloud computing is defined by five mandatory characteristics:
1. **On-Demand Self-Service:** Consumers can provision computing capabilities (server time, network storage) automatically without requiring human interaction with each service provider.
2. **Broad Network Access:** Capabilities are available over the network and accessed through standard mechanisms across heterogeneous client platforms (mobile phones, tablets, laptops, IoT gateways).
3. **Resource Pooling:** The provider's computing resources are pooled to serve multiple consumers using a multi-tenant model, with physical and virtual resources dynamically assigned according to demand. Location independence: the customer generally has no control or knowledge over the exact physical location of the hardware.
4. **Rapid Elasticity:** Capabilities can be elastically provisioned and released—automatically in some cases—to scale rapidly outward and inward commensurate with demand.
5. **Measured Service:** Resource usage is monitored, controlled, and reported transparently, providing metering based on pay-per-use billing models.

---

## 2. Cloud Deployment Models
* **Public Cloud:** Infrastructure is owned by a cloud provider (AWS, Azure, Google Cloud) and made available to the general public or large industry groups over the internet.
* **Private Cloud:** Infrastructure is operated exclusively for a single organization. May be managed internally or by a third party, hosted on-premises or off-premises.
* **Community Cloud:** Shared by several organizations with shared concerns (mission, security requirements, policy, compliance).
* **Hybrid Cloud:** Composition of two or more distinct cloud infrastructures (private, community, or public) that remain unique entities but are bound together by standardized technology enabling data and application portability (e.g., cloud bursting).

---

## Key Exam Takeaways
* **NIST 5 Characteristics:** On-Demand Self-Service, Broad Network Access, Resource Pooling, Rapid Elasticity, Measured Service.
* **Multi-Tenancy:** Multiple independent customers sharing the same pooled physical server hardware securely.
* **Rapid Elasticity:** Automatic scaling of computing power up or down based on real-time traffic spikes.
* **Hybrid Cloud:** Blending on-premises private cloud infrastructure with public cloud scale.
