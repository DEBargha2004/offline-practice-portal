# Chapter 27: Introduction to Python Programming — Part II: Files & Modules

## Core Concept
Real-world IoT applications require persisting sensor readings to local files, formatting structured datasets (such as CSV), handling runtime exceptions safely, and manipulating multimedia visual assets using external Python libraries.

---

## 1. File I/O Operations
* Files are accessed using the built-in `open(filename, mode)` function:
  * `'r'`: Read mode (default; errors if file does not exist).
  * `'w'`: Write mode (creates a new file or completely overwrites an existing file).
  * `'a'`: Append mode (writes new data to the end of the existing file without truncating it).
  * `'r+'`: Read and Write mode simultaneously.
* **Context Management (`with` statement):**
  * Using `with open(...) as f:` guarantees that the file handle is cleanly closed even if unhandled exceptions occur during execution.

---

## 2. Structured Data: CSV Handling
* **Comma-Separated Values (CSV):** Plain text tabular format where each line represents a data record, with fields separated by commas.
* Standard Python `csv` module provides `csv.reader()` and `csv.writer()` to read and record continuous time-series sensor logs (timestamps, temperatures, voltages) to disk.

---

## 3. Image Processing with PIL / Pillow
* Python Imaging Library (Pillow) provides image manipulation tools for IoT camera nodes:
  * Opening, cropping, resizing, rotating, and filtering images.
  * Preprocessing frames from security cameras before running edge machine learning classification models.

---

## 4. Modules and Packages
* **Modules:** Standalone Python files (`.py`) containing reusable functions, classes, and global variables.
* **Importing:** Managed via `import module_name` or `from module_name import specific_function`.
* **Standard IoT Libraries:** `math`, `time`, `socket`, `json`, and `os`.

---

## Key Exam Takeaways
* **File Append Mode:** Using `'a'` appends data to the end of a log file without deleting existing records.
* **Context Manager (`with`):** Ensures automatic and reliable file closing.
* **CSV Format:** Plain text tabular structure universally used for sensor datalogging.
* **Pillow Library:** Standard Python library used for image manipulation and edge computer vision preprocessing.
