# Chapter 29: Introduction to Raspberry Pi — Part II: Interfacing Peripherals

## Core Concept
Building functional IoT systems with a Raspberry Pi requires programming its 40-pin GPIO header in Python, capturing visual streams using dedicated camera ribbon interfaces, and deploying code using secure network file transfer protocols.

---

## 1. Programming GPIO in Python (`RPi.GPIO`)
* **Pin Numbering Schemes:**
  * `GPIO.BOARD`: Refers to physical pin numbers on the 40-pin header (1 through 40). Independent of SoC hardware revisions.
  * `GPIO.BCM`: Refers to Broadcom SoC channel numbers (e.g., GPIO 17, GPIO 27). Matches microcontroller labels directly.
* **Configuration Lifecycle:**
  1. `GPIO.setmode(GPIO.BCM)`: Declares the numbering scheme.
  2. `GPIO.setup(pin, GPIO.OUT)` or `GPIO.setup(pin, GPIO.IN)`: Defines pin direction.
  3. `GPIO.output(pin, GPIO.HIGH)`: Outputs 3.3V; `GPIO.LOW` outputs 0V.
  4. `state = GPIO.input(pin)`: Reads digital input state.
  5. `GPIO.cleanup()`: Resets all configured pins back to safe input states when exiting, preventing short-circuits on subsequent runs.

---

## 2. Dedicated Camera Interface: Pi Camera Module
* Connects directly to the Raspberry Pi board via a 15-pin flat ribbon cable into the **CSI (Camera Serial Interface)** port, bypassing USB bus bandwidth bottlenecks.
* Controlled in Python via the `picamera` library:
  * Initializing camera: `camera = picamera.PiCamera()`
  * Capturing still pictures: `camera.capture('image.jpg')`
  * Recording video: `camera.start_recording('video.h264')` / `camera.stop_recording()`
* Crucial for edge computer vision, license plate reading, and motion surveillance cameras.

---

## 3. Remote Development Tools & File Transfer
* **FileZilla (SFTP):** Connects to the Raspberry Pi over SSH File Transfer Protocol (Port 22) using the Pi's IP address, username, and password.
* Allows graphical drag-and-drop file transfers between a local development laptop and the headless Raspberry Pi file system.

---

## Key Exam Takeaways
* **Pin Numbering Options:** `GPIO.BOARD` (physical header pins 1-40) vs `GPIO.BCM` (Broadcom silicon channel numbers).
* **Mandatory Cleanup:** `GPIO.cleanup()` releases hardware pins safely on script termination.
* **CSI Interface:** High-speed Camera Serial Interface ribbon port dedicated to the Pi Camera.
* **SFTP Transfer Port:** Uses SSH port 22 for secure network file synchronization.
