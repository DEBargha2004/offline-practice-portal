# Chapter 59: Activity Monitoring — Part I: Foundations & Wearables

## Core Concept
Activity Monitoring involves continuous tracking and classification of human physical movements and behaviors using wearable sensors and mobile computing. It enables elderly fall detection, sports performance optimization, computer-generated animation (CGI), and proactive preventive healthcare.

---

## 1. Technological Approaches to Activity Monitoring
* **In-Place (On-Device) Monitoring:**
  * Sensor data processing, feature extraction, and machine learning classification occur entirely on the wearable or smartphone processor.
  * **Advantages:** Immediate real-time feedback, zero network bandwidth consumption, and total user privacy (raw sensor data never leaves the device).
  * **Disadvantages:** High battery drain on the wearable and limited to lightweight classification algorithms.
* **Network-Based Monitoring:**
  * Wearable sensors stream raw readings over wireless links to a remote cloud or fog server for processing.
  * **Advantages:** Allows complex deep learning models, multi-user trend analysis, and lightweight, low-power wearable designs.
  * **Disadvantages:** Requires continuous, reliable network connectivity; vulnerable to transmission latency and packet loss.

---

## 2. Sensor Sources for Activity Recognition
* **Dedicated Wearables:** Smart wristbands, chest straps, smart rings, and smart textiles equipped with inertial measurement units (IMUs).
* **Commodity Smartphone Sensors:** Built-in multi-axis accelerometers, gyroscopes, magnetometers, and barometric altimeters that track movement patterns without requiring extra specialized hardware.

---

## 3. Core Processing Pipeline
1. **Raw Sensor Acquisition:** Tri-axial acceleration (X, Y, Z) and rotational velocity.
2. **Preprocessing & Filtering:** Applying median and low-pass Butterworth filters to separate dynamic body motion from static gravitational acceleration (1g).
3. **Feature Extraction:** Calculating time-domain features (mean, variance, root mean square, peak-to-peak amplitude) and frequency-domain features (Fast Fourier Transform energy).
4. **Classification:** Machine learning algorithms (Decision Trees, Support Vector Machines, Neural Networks) categorizing activities: Walking, Running, Sitting, Climbing Stairs, or Falling.

---

## Key Exam Takeaways
* **In-Place vs. Network-Based:** In-place processes on-device for privacy and instant response; Network-based offloads to servers for complex deep learning.
* **Primary Hardware Sensors:** Tri-axial accelerometers and gyroscopes (IMUs).
* **Gravity Separation:** Low-pass filtering separates static 1g gravitational force from high-frequency dynamic human body movement.
* **Target Applications:** Fall detection for elderly care, sports analytics, and CGI motion capture.
