# Chapter 28: Introduction to Raspberry Pi — Part I: Hardware & OS

## Core Concept
The Raspberry Pi is a low-cost, credit-card-sized Single-Board Computer (SBC). While microcontrollers like Arduino handle real-time low-level pin toggling, the Raspberry Pi runs a full Linux operating system, offering high processing speed, gigabytes of RAM, onboard networking, and rich multimedia capabilities for advanced IoT edge computing.

---

## 1. Single-Board Computer (SBC) Architecture
* Unlike traditional PCs with separate motherboards, graphics cards, and daughterboards, an SBC integrates the CPU, GPU, system RAM, USB controllers, and network interfaces onto a single printed circuit board.
* **System-on-Chip (SoC):** Integrates multi-core ARM Cortex application processors with a Broadcom VideoCore GPU.
* **Storage:** Operates without a mechanical hard drive; boots and runs its operating system from a MicroSD card.
* **Connectivity:** Built-in Gigabit Ethernet, dual-band Wi-Fi (2.4 GHz and 5 GHz), and Bluetooth / BLE.

---

## 2. The 40-Pin GPIO Header
The Raspberry Pi features a standardized 40-pin General Purpose Input/Output header operating at **3.3V logic levels** (applying 5V to a Pi GPIO pin will permanently destroy the SoC):
* **Digital I/O Pins:** General pins for digital input/output.
* **Power Pins:** Dedicated 5V pins, 3.3V pins, and multiple Ground (GND) return pins.
* **Hardware Communication Buses:**
  * **UART:** Serial communication via TXD (GPIO 14) and RXD (GPIO 15).
  * **I2C:** Inter-Integrated Circuit bus via SDA (GPIO 2) and SCL (GPIO 3).
  * **SPI:** Serial Peripheral Interface via MOSI, MISO, SCLK, and CE pins.
* **Important Hardware Note:** Raspberry Pi has **no built-in analog input pins** (lacks an onboard ADC). Reading analog sensors requires an external ADC chip (such as the MCP3008) or a microcontroller coprocessor.

---

## 3. Operating System: Raspberry Pi OS (formerly Raspbian)
* A Debian-based Linux distribution optimized specifically for Raspberry Pi ARM hardware.
* Standard access tools:
  * **SSH (Secure Shell):** Remote headless command-line management over the network on port 22.
  * **VNC (Virtual Network Computing):** Remote graphical desktop access.

---

## Comparison: Arduino vs. Raspberry Pi
| Feature | Arduino Uno | Raspberry Pi (e.g., 3/4) |
| :--- | :--- | :--- |
| **Category** | Microcontroller Board (MCU) | Single-Board Computer (SBC) |
| **Processor** | 8-bit ATmega328P @ 16 MHz | 64-bit Multi-Core ARM @ 1.2–1.5+ GHz |
| **Operating System** | None (runs bare-metal firmware) | Full Linux OS (Raspberry Pi OS) |
| **RAM** | 2 KB SRAM | 1 GB to 8 GB LPDDR4 |
| **Logic Voltage** | 5V | **3.3V strictly** |
| **Analog Inputs** | 6 onboard 10-bit ADC channels | None (requires external ADC) |
| **Best Used For** | Simple real-time sensor control, battery devices | Video processing, edge AI, gateways, web servers |

---

## Key Exam Takeaways
* **Logic Level Constraint:** Raspberry Pi GPIO operates strictly at 3.3V; 5V signals will damage the board.
* **Analog Limitation:** Has no native ADC; reading analog sensors requires an external ADC chip (e.g., MCP3008).
* **Operating System Base:** Debian Linux (Raspberry Pi OS).
* **Remote Management:** SSH (port 22) enables headless network administration without a monitor.
